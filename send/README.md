# АРХИТЕКТУРА:

Данные, по одной строке за раз, извлекаются генераторами из файлов, а затем последовательно проходят через разные этапы - фильтрация, работа агрегатных функций, и.т.д. Есть сходство с функциональным программированием, а так же с SQL запросами.
Используются паттерны и концепции: Стратегия, Шаблонный Метод, Абстрактный класс, Наблюдатель, Прототип, Фасад.

## ЧАСТИ ПРОГРАММЫ:

Почти вся программа поделена на классы, каждый из которых выполняет свою задачу.
Везде 2 уровня наследования - суперкласс и подкласс.
Суперкласс - это:

1) интерфейс для всех подклассов (имена методов, их аргументы, тип возвращаемого значения, ...).
2) Готовый метод, который все подклсассы просто наследуют.
3) Метод, который нужно вызвать в аналогичном методе подкласса, выполнив перед его вызовом некоторые действия.

ЗАГРУЗЧИКИ - получают данные из файлов.

ТРАНСФОРМЕРЫ - пропускают через себя данные, занимаются преобразованием данных (фильтрацией).

МЕТРИКИ - собирают данные из множества записей (сумма, количестово, и.т.д.)

ПРОЦЕССОРЫ - пропускают через себя данные, содержат интерфейс для подключения Метрик, а так же занимаются группировкой.

СОЗДАТЕЛЬ ОТЧЕТОВ - при вызове с передачей аргументов из командной строки выполняет метод, соответствующий флагу --report, который выдает результат.

# МЕЛКИЕ РЕШЕНИЯ:

## ИМПОРТ БИБЛИОТЕК:
Обычно все библиотеки рекомендуют импортировать в самом начале файла,
но, если различные запуски программы требуют различных библиотек (к примеру, по библиотеке для каждого типа файла - csv, txt, odt, ...), и при каждом запуске программы методы, требующие эти библиотеки, выполняются один раз, то ради ускорения можно поместить в методы (чтобы при запуске, в начале выполнения не было импорта 100 разных библиотек для всех возможных случаев).
Как альтернатива - можно собирать разные версии программы (к примеру, каждая версия под свой тип файла) и тогда уже вынести все импорты в начало.

# КОМАНДЫ:

Установка виртуального окружения:
python3 -m venv .venv

Вход в виртуальное окружение:
source .venv/bin/activate

Установка библиотек:
pip install -r requirements.txt

Запуск:
python3 main.py --files economic1.csv economic2.csv --report average-gdp

Тестирование:
python3 -m pytest

## ПАРАМЕТРЫ СО ЗНАЧЕНИЯМИ ПО УМОЛЧАНИЮ:

(1) Если указаны при инициализации объекта экземпляра подкласса, то используются они.
(2) Если не указаны - используются значения по умолчанию в подклассе.
(3) Если значений по умолчанию в подклассе нет - то используются значения по умолчанию из суперкласса.

Если нужно создать значение по умолчанию для подкласса - то делаем его значением по умолчанию для параметра в \__init__.

Благодаря выражению вида value = value or self.DEFAULT_VALUE, мы из подкласса можем получить настройки по умолчанию из суперкласса, если необходимо.
